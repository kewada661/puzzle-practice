# Puzzle Practice
ReactRouter + Vite App. Used with [puzzle-practice-server](https://github.com/kewada661/puzzle-practice-server).

This app helps users complete the final two steps of solving a (3x3) puzzle cube: orienting and permuting the last layer. The app serves the user with a scramble that takes a cube from a solved state to specific OLL or PLL case that can be "solved" with a corresponding algorithm. The app records times and measures performance for each case and targets cases with which the user is weakest.
